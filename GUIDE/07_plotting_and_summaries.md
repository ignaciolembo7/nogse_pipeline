# Plotting And Summaries

Plotting is split between shared primitives and experiment-specific wrappers.

## Shared Plotting Primitives

Reusable plotting code lives in:

- `src/plottings/core.py`
- `src/plottings/contrast_vs_g.py`
- `src/plottings/fit_plot_style.py`
- `src/plottings/plot_rotation.py`
- `src/plottings/signal_image_grid.py`

`src/plottings/core.py` provides common single-series and multi-series plot
helpers. Fit-specific modules pass labels, uncertainty arrays, title strings,
and output paths into these helpers.

## Monoexponential Summaries

Monoexponential summary plots are generated by:

- `scripts/plot_monoexp_D_vs_time.py`
- `src/monoexp_fitting/plot_monoexp_D_vs_time.py`

The combined tables use:

- `D_mean_mm2_s` for plotted diffusivity;
- `D_std_mm2_s` for the plotted uncertainty band.

In the current implementation, `D_std_mm2_s` is derived from the fitted
`D0_err_mm2_s` values. When several fits collapse into one plotted point, the
errors are combined as a root-mean-square value.
